StudioDesk — AI support & QA agent for game studios

StudioDesk answers player and QA questions with cited sources, spots duplicate bug reports before they reach your tracker, and drafts GitHub issues that are filed only after a person presses Confirm. It searches the studio's own bug reports, crash logs, patch notes and support docs, and you can use it by typing or by talking to it.

Demo data: the game Starfall Outpost is fictional. The knowledge base holds 66 bug reports, 25 crash logs, 10 patch notes and 4 support docs, all made up for this demo.
